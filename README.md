> **AutoDoc TH** คือเว็บแอปพลิเคชันที่สร้างขึ้นมาเพื่อแก้ปัญหาการจัดหน้าเอกสาร Word (`.docx`) สำหรับนักเรียน ครู และนักวิจัยไทยโดยเฉพาะ เปรียบเสมือน **"โปรแกรมเสริมคู่ใจของ Microsoft Word"** ที่แยกออกมาให้จัดหน้าได้ง่าย รวดเร็ว และเป็นระเบียบกว่าเดิม

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- 🎛️ **แถบเครื่องมือ Word Ribbon Companion:**
  - **แท็บหน้าแรก:** ปรับฟอนต์ (TH Sarabun PSK 16pt, Prompt), ตัวหนา/เอียง/ขีดเส้นใต้, จัดกึ่งกลาง/ชิดซ้าย/เต็มบรรทัด (Thai Distributed), และย่อหน้า 0.5 นิ้ว
  - **แท็บเค้าโครง:** ตั้งระยะขอบโครงงาน 5 บท (บน 1.5", ซ้าย 1.5", ขวา 1.0", ล่าง 1.0") และรีเซ็ตการรันเลขหน้า
  - **แท็บแทรก:** แทรกตัวแบ่งหน้า (Page Break), ตารางมาตรฐาน 5 บท, กล่องรูปภาพพร้อมที่มา, และสร้างสารบัญ (TOC) อัตโนมัติ
  - **แท็บ Data Science:** ปุ่มวิเศษจัดหน้าทั้งเล่มอัตโนมัติในคลิกเดียว
- 📑 **จำลองกระดาษ A4 ต่อเนื่อง (Continuous Multi-Page Canvas):**
  - นำเข้าไฟล์ Word แล้วแยกหน้ากระดาษตามจริงทันที
  - สามารถสลับประเภทของแต่ละแผ่นได้ (หน้าปก, กิตติกรรมประกาศ, บทคัดย่อ, บทที่ 1-5)
  - รันเลขหน้าไทย (ก, ข, ค) และเลขอารบิก (1, 2, 3) อัตโนมัติตามประเภทส่วน
- 📥 **ส่งออกเป็นไฟล์ Word (.docx) หลายหน้า:**
  - รองรับการ Export เป็นไฟล์ `.docx` แท้ที่แบ่งหน้าตามเกณฑ์ หรือสั่งพิมพ์เป็น PDF ขนาด A4 ได้ทันที

---

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกเปิดไฟล์ `index.html` บน Google Chrome หรือ Edge
2. ลากไฟล์ `.docx` เข้ามาในช่องอัปโหลด หรือกด **"โหลดตัวอย่าง 4 หน้า (OCOP)"**
3. ใช้แถบ Ribbon ด้านบนจัดแต่งหน้ากระดาษเหมือนใน Word
4. กด **"ดาวน์โหลด Word (.docx)"** เพื่อรับไฟล์ที่จัดหน้าเสร็จสมบูรณ์
